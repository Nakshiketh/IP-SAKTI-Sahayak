# Demo script

Written in Phase 13, rehearsed twice, with an offline-safe fallback ready. Sketched here so the
build knows what it is aiming at.

Five minutes, in this order:

1. Classify a product — the adaptive flow reaches a class in under eight questions.
2. Ask an Indian question — answer with claim-level citations, confidence with its reason.
3. Open a source — show the actual retrieved passage, its section path and effective date.
4. Flip the jurisdiction toggle — the answer set visibly swaps. Nothing blends.
5. Trigger an abstention deliberately — it is a feature, not a failure.
6. Show the evaluation numbers, including the ones that are not good yet.

Nothing in this script is built yet. See `docs/MASTER_BUILD.md`.
